# Online resume starter
Review and personalize the HTML, CSS and JavaScript yourself before submitting. Verify all dates, claims and public contact details. Open index.html locally. The theme button switches between light and dark mode and remembers the selection.

To publish: create a public GitHub repository named online-resume, upload index.html, style.css and script.js to its root, then open Settings > Pages > Deploy from a branch > main > / (root) > Save. Open the actual Pages URL from Settings and test it. Replace the placeholders in the Word report with the real repository and live URL; update screenshots after your own edits. Keep the links accessible until the semester ends.
